# Pairus IA: Seu Site Grátis

vou criar uma agencia de IA focada na criação de sites gratuitos para comercios locais sou parceiro da wix e quero ajudar esses comercios a entrarem no digital
a principio vou criar apenas landing pages desses profissionais como dentistas, advogados, eletrecistas, etc

 precisamos fazer uma pagina de captura para os clientes e nessa pagina a headline deve ser bem forte, algo tipo parabens vc esta apto a receber um site gratuito (Ja que o cliente não ira pagar pelo site) coloque que a pairus IA (Nome da agencia) ira fazer toda a criação do site do cliente e que somos parceiros oficiais da WIX. a promessa deve ser bem forte para converter o cliente e deve haver um botão de redirecionamento para o whatsapp para ficar mais harmonico as cores dessa pagina devem combinar com a logo e por ultimo e mais importante, nessa pagina deve haver exemplos de outras paginas como se fosse um portifólio para o cliente ter uma noção da qualidade do nosso trabalho 
estou enviando a logo da agencia em anexo para que a use na pagina e use ela para decidir a paleta de cores, deve combinar com a da logo
